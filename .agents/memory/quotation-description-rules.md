---
name: Quotation product descriptions
description: User requirements for read-only product descriptions and long text in quotations.
---

Product descriptions appear below the product name and are not editable in quotations. Staff may enter long descriptions; show the complete text in the form, detail, public approval, and PDF, including across PDF page breaks.

**Why:** The user explicitly requested read-only descriptions and warned that staff will enter long text.

**How to apply:** Keep description editing in the product catalog. Do not introduce truncation or a quotation-specific description editor when adjusting these views or PDF layouts.
