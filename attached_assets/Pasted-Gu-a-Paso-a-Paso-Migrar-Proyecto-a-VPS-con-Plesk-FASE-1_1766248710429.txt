Guía Paso a Paso: Migrar Proyecto a VPS con Plesk
FASE 1: Preparar la VPS
1.1 Conectarse por SSH
ssh root@74.208.13.243
# Ingresa la contraseña inicial de Plesk
1.2 Actualizar el sistema
dnf update -y
dnf install -y git curl wget
1.3 Instalar Node.js 20 LTS
curl -fsSL https://rpm.nodesource.com/setup_20.x | bash -
dnf install -y nodejs
node --version  # Verificar: v20.x.x
npm --version
1.4 Instalar PM2 (gestor de procesos)
npm install -g pm2
pm2 startup systemd
FASE 2: Configurar PostgreSQL
Opción A: Mantener Neon (Recomendado - más fácil)

Solo necesitas asegurarte de que la VPS pueda conectarse a Neon
Tu DATABASE_URL actual seguirá funcionando
Opción B: Instalar PostgreSQL local

# Instalar PostgreSQL 15
dnf install -y postgresql15-server postgresql15
postgresql-setup --initdb
systemctl enable postgresql
systemctl start postgresql
# Crear usuario y base de datos
sudo -u postgres psql
CREATE USER joper_user WITH PASSWORD 'tu_password_segura';
CREATE DATABASE joper_db OWNER joper_user;
GRANT ALL PRIVILEGES ON DATABASE joper_db TO joper_user;
\q
# Migrar datos desde Neon
pg_dump "postgresql://neondb_owner:npg_jcnYh5aq1mfV@ep-square-cloud-ah5gpe6i.c-3.us-east-1.aws.neon.tech/neondb?sslmode=require" --no-owner > backup.sql
psql -U joper_user -d joper_db < backup.sql
FASE 3: Clonar el Proyecto
3.1 Crear directorio de la aplicación
mkdir -p /var/www/joper
cd /var/www/joper
3.2 Clonar desde GitHub (si tienes repo) o subir archivos
# Si tienes GitHub:
git clone https://github.com/tu-usuario/tu-repo.git .
# Si no, desde Replit descarga el ZIP y súbelo con SCP:
# Desde tu máquina local:
scp -r ./proyecto root@74.208.13.243:/var/www/joper/
3.3 Instalar dependencias
cd /var/www/joper
npm install
FASE 4: Configurar Variables de Entorno
4.1 Crear archivo .env
nano /var/www/joper/.env
4.2 Contenido del .env:
NODE_ENV=production
PORT=5000
# Base de datos (elige una opción)
# Opción A - Neon:
DATABASE_URL=postgresql://neondb_owner:npg_jcnYh5aq1mfV@ep-square-cloud-ah5gpe6i.c-3.us-east-1.aws.neon.tech/neondb?sslmode=require
# Opción B - Local:
# DATABASE_URL=postgresql://joper_user:tu_password@localhost:5432/joper_db
# Sesiones
SESSION_SECRET=tu_session_secret_seguro_aqui
# Email
MAILERSEND_API_KEY=tu_api_key
RESEND_API_KEY=tu_api_key
# Google Cloud Storage (credenciales)
GOOGLE_APPLICATION_CREDENTIALS=/var/www/joper/gcs-credentials.json
DEFAULT_OBJECT_STORAGE_BUCKET_ID=tu_bucket_id
4.3 Subir credenciales de Google Cloud Storage
# Desde tu máquina local, sube el archivo JSON de credenciales:
scp gcs-credentials.json root@74.208.13.243:/var/www/joper/
chmod 600 /var/www/joper/gcs-credentials.json
FASE 5: Compilar y Ejecutar
5.1 Compilar la aplicación
cd /var/www/joper
npm run build
5.2 Crear archivo de configuración PM2
nano /var/www/joper/ecosystem.config.js
Contenido:

module.exports = {
  apps: [{
    name: 'joper-app',
    script: 'dist/index.js',
    cwd: '/var/www/joper',
    instances: 1,
    autorestart: true,
    watch: false,
    max_memory_restart: '1G',
    env: {
      NODE_ENV: 'production',
      PORT: 5000
    }
  }]
};
5.3 Iniciar con PM2
cd /var/www/joper
pm2 start ecosystem.config.js
pm2 save
pm2 list  # Verificar que está corriendo
FASE 6: Configurar Nginx (Reverse Proxy)
6.1 Configurar en Plesk
Entra a Plesk: https://74.208.13.243:8443
Ve a Sitios web y dominios
Añade tu dominio o usa la IP
En Configuración de Apache y nginx → Configuración adicional de nginx:
location / {
    proxy_pass http://127.0.0.1:5000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection 'upgrade';
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_cache_bypass $http_upgrade;
}
FASE 7: Configurar SSL/HTTPS
En Plesk:

Ve a Sitios web y dominios → Tu dominio
Clic en Certificados SSL/TLS
Selecciona Let's Encrypt
Marca "Redirigir HTTP a HTTPS"
Clic en Obtener gratis
